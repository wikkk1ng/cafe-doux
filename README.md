# Café Doux — сайт кофейни-пекарни

Одностраничный сайт независимой кофейни-пекарни с интерактивным 3D-макароном.
Без фреймворков: HTML, CSS и JavaScript, 3D на [three.js](https://threejs.org/).

**Сайт:** https://wikkk1ng.github.io/cafe-doux/

## Что умеет

- **3D-макарон в первом экране.** Реагирует на курсор и прокрутку. В разделе «Как он устроен» по мере прокрутки раскладывается на слои: крышечка, ганаш и нижняя половинка. Пока 3D грузится, на его месте стоит картинка-заглушка, отрисованная из той же сцены, поэтому подмены не видно.
- **Конструктор коробки.** 3D-коробка на 6 или 12 макаронс, 6 вкусов, подпись на открытку. Заказ уходит в Telegram одним сообщением. Состав сохраняется между визитами. Без WebGL коробка показана плоской схемой, и заказ собрать всё равно можно.
- **Вечерний режим.** Включается сам с 19:00 до 6:00 или кнопкой в шапке. Новая тема «разливается» кругом из кнопки, а свет в 3D-сценах плавно меняется на тёплую лампу.
- **Детали:** свой курсор, магнитные кнопки, заголовки появляются по словам.
- **Страница 404:** ноль в «404» — это 3D-макарон. Он укатывается, его можно толкать курсором или пальцем и закатить обратно.

## Скорость и доступность

Lighthouse, чистовая сборка:

| | Производительность | Доступность | Практики | SEO |
|---|---|---|---|---|
| Телефон | 93 | 100 | 100 | 100 |
| Компьютер | 100 | 100 | 100 | 100 |

Как этого добились:
- **3D.** Модель заранее подготовлена скриптом (`build/bake.mjs`): упрощена, сжата meshopt и разрезана на слои. На телефонах грузится облегчённая версия, и только после первого касания. Кадры рисуются только когда что-то меняется.
- **Стили.** Встроены в страницу, фото в WebP нескольких размеров (`srcset`).
- **Шрифты.** Свои файлы, только с нужными символами: 4 файла вместо 10.
- **Доступность.**
  - Контраст текста не ниже 4.5 в обеих темах.
  - Конструктором можно пользоваться с клавиатуры и экранного диктора.
  - Учитывается настройка «уменьшить движение».

## Технологии

- HTML, CSS (custom properties, View Transitions API), JavaScript-модули
- three.js 0.169 — лежит в проекте (`vendor/three`), без CDN
- Подготовка модели: glTF-Transform и meshoptimizer; исходная модель сгенерирована в Hunyuan3D
- Сборка: esbuild, обработка фото: sharp, шрифты: fontTools

## Структура

```
index.html, 404.html   страницы
css/style.css          стили (дневная и вечерняя темы)
js/                    main.js — интерфейс; hero-scene.js, box-scene.js, notfound.js — 3D-сцены;
                       box.js — конструктор коробки; macaron-model.js — загрузка модели и материалы
assets/                шрифты, фото, модели макарона (.glb)
vendor/three/          нужные файлы three.js
build/                 release.mjs — чистовая сборка в dist/; images.mjs — фото в WebP;
                       fonts.py — шрифты; bake.mjs — подготовка 3D-модели; cursor.svg — исходник курсора
serve.py               локальный сервер
```

## Запуск у себя

Нужен Python 3:

```bash
python serve.py
```

Сайт откроется на http://localhost:5173.

Полезные параметры адреса:
- `?theme=day` и `?theme=evening` — тема;
- `?no3d` — сайт без 3D, как на устройстве без WebGL;
- `?poster` — пересохранить картинку-заглушку макарона.

## Сборка и публикация

Сайт публикуется на GitHub Pages сам: при каждом `push` в ветку `main` GitHub Actions
собирает чистовую версию (`build/release.mjs` → `dist/`) и выкладывает её.
Один раз нужно включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Собрать и посмотреть чистовую версию локально (нужен Node.js 20+):

```bash
cd build && npm install && npm run build && cd ..
python serve.py dist
```

## Перед запуском для настоящей кофейни

- `js/box.js` → `TELEGRAM_USERNAME`: аккаунт, куда приходят заказы. Пока он пуст, кнопка копирует заказ в буфер.
- Ссылки на соцсети в футере (`index.html`).
